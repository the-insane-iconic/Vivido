# Vivido Chrome Extension

The official Chrome Extension for **Vivido — AI Visual PDF Companion**.

## How to Install in Google Chrome / Brave / Edge

1. Open your browser and navigate to `chrome://extensions/`.
2. Toggle **Developer mode** in the top right corner.
3. Click **Load unpacked** in the top left corner.
4. Select the `extension/` folder in this repository.
5. The **Vivido Companion** icon will now appear in your browser extension bar!

## Features

- **Context Menu Integration**: Right-click any PDF link or open PDF page and click **"Read in Vivido with Visual Companion"**.
- **Quick Launch**: Click the toolbar icon to launch your local or deployed Vivido app.
- **Configurable URL**: Set your local (`http://localhost:5173`) or deployed Render production URL in the popup.
